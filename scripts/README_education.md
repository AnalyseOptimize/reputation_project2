# Расчёт образования и экспертизы

Запуск из корня проекта, Python 3.10+; сторонние библиотеки не нужны:

```sh
python3 scripts/process_education.py
python3 -m unittest discover -s tests -v
```

Можно запускать скрипт по абсолютному пути из любого каталога. Пути по умолчанию
определяются относительно самого скрипта, а пользовательские аргументы — относительно
рабочего каталога.

Вход: `education/data/*_person_info.json`, только непосредственное содержимое
каталога. Резервные копии и `.json.tmp` не читаются. Выход:
`educationn/eduction_processed.csv` (написание сохранено точно из `PROMPT.md`).
CSV использует UTF-8 с BOM, разделитель — запятая. ФИО и должность сохраняются
как в исходном файле, включая имена на латинице. Одна строка соответствует
человеку в компании данного файла. Данные одного человека из разных компаний
не объединяются. Повтор `(ticker, name)` вызывает ошибку вместо молчаливой потери данных.

```sh
python3 scripts/process_education.py --input-dir education/data --output education/education_processed.csv
python3 scripts/process_education.py --research-missing-dates complete-only
```

## Колонки результата

| Колонка | Смысл |
| --- | --- |
| `ticker`, `name`, `role` | Тикер компании, исходное имя, исходное `current_role` |
| `education_secondary` | Наивысшее подтверждённое образование — среднее / среднее специальное |
| `education_bachelor` | Наивысшее подтверждённое образование — бакалавриат |
| `education_master` | Наивысшее подтверждённое образование — магистратура или специалитет |
| `education_doctoral` | Кандидат, доктор наук или PhD, без разделения |
| `education_level_unknown` | Ни один из четырёх уровней не установлен |
| `has_mba_emba` | MBA/EMBA в любой записи образования или степеней |
| `has_foreign_education` | Есть положительное свидетельство зарубежного учебного заведения |
| `has_professional_retraining` | Явно указана профессиональная переподготовка |
| `has_law_education`, `has_economics_education` | Юридическая и экономическая направленность, независимо друг от друга |
| `publications_count`, `patents_count` | Доступное количество публикаций / патентов; пусто, если есть только упоминание без количества |
| `publications_count_is_lower_bound`, `patents_count_is_lower_bound` | Количество неполное / приблизительное либо не установлено |
| `has_research_experience` | Есть запись в `research_experience`, независимо от дат |
| `research_experience_years` | Сумма длительностей исследовательских эпизодов |
| `experience_years_same_sector` | Стаж в секторе компании данного файла |
| `experience_years_same_industry` | Стаж в отрасли компании данного файла |
| `experience_years_same_industry_group` | Стаж в отраслевой группе компании данного файла |
| `professional_experience_years` | Суммарный профессиональный стаж |
| `has_experience_same_sector`, `has_experience_same_industry`, `has_experience_same_industry_group` | Есть релевантная запись, в том числе без дат |
| `has_other_company_management` | В истории есть управленческая должность / совет директоров другой компании |
| `current_company_experience_years` | Стаж непосредственно в компании данного файла |

Ноль в дамми означает отсутствие положительного свидетельства в локальных данных,
а не доказанное отсутствие соответствующего образования или опыта. Ноль лет
означает отсутствие включённых в расчёт интервалов, а не обязательно отсутствие
опыта. Общие длительности могут превышать календарный возраст карьеры вследствие
суммирования совмещаемых должностей, как требуется в задании.

## Образование

Проверены фактические значения `field`, `program`, `program_or_specialty`,
`program_or_field`, `field_or_program`, `specialization` и полей квалификации.
В данных встречаются, например, «Юриспруденция», «Правоведение», `Law`,
«Финансы и кредит», `Accounting`, «Менеджмент», а также смешанное
`Economics and law of Russia and Eastern Europe`. Полные значения с частотами
и результатами классификации сохраняются в `education_fields_audit.csv`.
Явные регулярные выражения находятся в `utils/education_rules.py`.

Экономическое образование трактуется широко: экономика, финансы, бухгалтерский
учёт, аудит, банковское дело, коммерция, маркетинг и бизнес-менеджмент, включая
MBA. Государственное управление и управление техническими системами сами по себе
не относятся к экономическому образованию. Классификация использует направления
и квалификации на любом уровне, включая переподготовку и сертификацию.
Название университета не используется для вывода о специальности.

Наивысший уровень выбирается по иерархии, а не по наиболее позднему году:
научная степень выше магистратуры/специалитета, те выше бакалавриата и среднего
образования. Сначала используется нормализованное `qualification_degree`, затем,
при его отсутствии или `Unknown`, явные текстовые обозначения степени.
MBA не вытесняет основной уровень. Неоконченная аспирантура, звания профессора,
доцента и академика сами по себе не дают научной степени. Из общего «высшее
образование» или квалификации «инженер» уровень не домысливается.

Переподготовка определяется по явным словам о переподготовке/переквалификации
в программе, квалификации или описании записи. Все `Professional certification`
и `Executive education` автоматически переподготовкой не считаются; повышение
квалификации также не равнозначно переподготовке. Само название института
переподготовки недостаточно.

В исходной выгрузке нет отдельного поля страны. Для зарубежного образования
используется явный список шаблонов иностранных учреждений/мест в
`FOREIGN_INSTITUTION_PATTERN`. Это воспроизводимый показатель по учреждению,
но физическое пребывание человека за границей исходными данными подтверждается
не всегда. Совместные программы с российскими учреждениями, явно обозначенными
в названии, не считаются зарубежными без отдельного поля страны. CFA, ACCA,
IoD и другие международные сертификаты сами по себе не доказывают зарубежного
обучения. Вузы вне территории России, включая другие бывшие республики СССР,
относятся к зарубежным независимо от года обучения. Неопознанные учреждения
не дают положительного признака. Список решений доступен в `education_records_audit.csv`.

## Даты и компании

Год извлекается из `start_year` / `end_year`, затем из `start_date` / `end_date`
или `start` / `end`. Поддерживаются целые годы и ISO-даты. Тексты с диапазонами
и неопределённые значения не превращаются в точные годы.

Эпизоды упорядочиваются по известному началу, а при его отсутствии — по известному
окончанию. Если начало отсутствует, оно восстанавливается из **исходного**
окончания непосредственно предыдущего эпизода при непротиворечивых датах.
Полностью недатированную запись невозможно расположить во времени; такая запись
не получает начало по случайному соседству в JSON и не входит в длительности.

Отсутствующее окончание — следующее строго более позднее начало в полной истории,
до фильтрации по компании/отрасли; при его отсутствии — 2024. Эпизоды с одинаковым
началом считаются параллельными. Каждый интервал учитывается отдельно по формуле
`end - start + 1`, включая оба года. Конфликтующие интервалы исключаются и
отмечаются в аудите. Явные окончания после 2024 обрезаются на 2024, а эпизоды,
начинающиеся позже 2024, исключаются: длительности рассчитаны на момент сбора,
даже если в JSON уже присутствуют сведения 2025–2026 годов. Будущие датированные
эпизоды также не дают индикаторов релевантного профессионального опыта.
Образование и научные количества берутся из представленных записей без
ретроспективной реконструкции на 2024: для такой реконструкции данных недостаточно.

**Допущение для исследовательского опыта:** незавершённое в `PROMPT.md` правило
по умолчанию трактуется так же, как профессиональный опыт. Альтернатива
`--research-missing-dates complete-only` учитывает только эпизоды с обеими датами.
Индикатор наличия исследовательского опыта в обоих режимах не зависит от дат.

Сопоставление `sector`, `industry`, `industry_group` использует отдельное
сравнение каждого поля без учёта регистра и лишних пробелов. Два пропуска
не считаются совпадением. Для распознанной текущей компании недостающие
отраслевые поля берутся из корня её JSON. Для других организаций отрасль
по названию не угадывается.

Компания наблюдения определяется корнем файла, а не другими текущими должностями
человека. Сравниваются нормализованные названия без организационно-правовой формы
и явно заданные алиасы в `COMPANY_ALIASES`. Совпадения по подстроке/нечёткому
сходству не используются. Дочерние юрлица не объединяются автоматически с
головной компанией. Для записей с несколькими организациями через `/` стаж
присваивается текущей компании только если все названия — её алиасы. Например,
агрегированную запись `Ozon / Internet Solutions LLC / Ozon Holdings PLC`
нельзя полностью отнести к одному юрлицу; она остаётся в общем стаже.

Управленческий опыт другой компании определяется по полю должности в
`professional_experience`: совет директоров, наблюдательный совет, правление,
директор, президент, руководитель и английские эквиваленты. Советники и помощники
руководителя сами по себе не считаются руководителями. Явные государственные
органы, университеты и научные институты исключаются из этого индикатора.
Опыт исторический: прекращение роли до 2024 не обнуляет признак.

## Научные количества и проверка

Простая длина массива неприменима: одна запись может означать 502 публикации.
Явный агрегат используется как количество; обороты «включая …» не добавляют
повторно подмножества, независимые категории суммируются (14 книг + 193 статьи).
Отдельные названия/номера патентов дедуплицируются. Агрегат и перечисленные работы
не складываются, поскольку список обычно является частью агрегата: используется
максимум. Для «более 50» сохраняется консервативная граница 50 с флагом неполного
количества. Если есть только отдельные работы, их число — нижняя граница.
Профиль автора или упоминание патентной активности без количества не считаются
одной работой: количество остаётся пустым. Авторские свидетельства и изобретения,
указанные в исходном массиве `patents`, включаются в патентный показатель.
Пустой исходный массив даёт 0 как отсутствие зарегистрированных в выгрузке работ.

Рядом с основным CSV создаются:

- `education_fields_audit.csv`: исходные значения, частоты и классификация направлений;
- `education_records_audit.csv`: решение по уровню и зарубежному учреждению для каждой записи;
- `experience_audit.csv`: исходные и использованные даты, включённые годы и причина обработки;
- `processing_summary.json`: число компаний/людей, выбранный режим дат и сводка исключений.

Тесты проверяют иерархию образования, MBA, смешанные специальности, переподготовку,
зарубежные и совместные программы, восстановление дат, пересечения, недатированные
релевантные записи, алиасы без объединения дочерних обществ и научные агрегаты.
Исходные JSON и ноутбук не изменяются. Скрипт формирует признаки для дальнейшего
использования в индексе; веса индекса в эту задачу не входят.
